# Experiment scripts

The experiments behind the paper's figures and tables, in the order how they appear in the paper. The durations of the experiments are approximate.

## Experiments

Paths are relative to `scripts/`. The Pi drivers in `benchmarking/e2e/navi/` are run from the Pi's working directory, which
holds that directory's contents together with an aarch64 build of NebulaStream (`bin/`), the models and the datasets.

| Paper | Script                                                                                                                                                                                                                                                                                                                                                                         | Hardware | Duration |
|---|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---|---|
| Fig. 1: P95 latency of NAVI, Flink + OpenVINO and TorchServe on three workloads | `benchmarking/e2e/navi/run_pi_cwru_tuning.sh` (CWRU), `benchmarking/e2e/navi/run_pi_systems_tuning.sh` (Waymo, MUSAN), each a pilot over every system's parallelism, then 5 repetitions of the chosen settings through `benchmarking/e2e/navi/scripts/run_systems.sh`; Flink's start-up split: `benchmarking/e2e/navi/run_pi_flink_startup.sh`                                 | Pi | ~6 h (1.1 h CWRU, 4.3 h Waymo and MUSAN, 0.5 h Flink start-up) |
| Batched inference micro-benchmark (`batch-microbench.pdf`) | `BatchInferenceMicrobenchmark` (built from `nes-physical-operators/tests`) with `--backend openvino --records 1048576 --repetitions 1 --batch-sizes 1,2,4,8,16,32,64,128,256,512,1024,2048,4096`                                                                                                                                                                               | Laptop | ~1 h |
| Thread budget: SPE workers x OpenVINO threads (`threading.pdf`) | `benchmarking/e2e/run_threading.sh` (capacity, 10 repetitions) and `benchmarking/e2e/run_threading_lat.sh --repetitions 5` (latency), then `benchmarking/e2e/process_threading_lat.py`                                                                                                                                                                                         | Server | ~30 h (23 h capacity, 7 h latency) |
| Prediction cache scope micro-benchmark (`caching-microbench.pdf`) | `PredictionCacheScopeMicrobenchmark` (built from `nes-physical-operators/tests`) with its default options                                                                                                                                                                                                                                                                      | Laptop | ~45 min |
| Batch size vs. source rate: latency and sustainable throughput (`batch-rate-throughput-column.pdf`) | `benchmarking/e2e/navi/run_pi_batch_rate_rerun.sh`, which runs `benchmarking/e2e/navi/scripts/run_batch_rate.sh` and `run_batch_throughput.sh` (3 repetitions each)                                                                                                                                                                                                            | Pi | ~5.5 h (4 h latency, 1.7 h throughput) |
| Post-join batching decision (`post-join-choice.pdf`) | Pi: `benchmarking/e2e/navi/run_pi_fan_rerun.sh` (the profiling pilot `run_post_join_pilot.sh`, then `run_post_join.sh`, 3 repetitions). Server: the same two scripts in `benchmarking/e2e/navi/scripts/`, pinned to 4 cores (`taskset -c 8-11`)                                                                                                                                | Pi, Server | Pi ~3 h, Server ~4 h |
| Table: sensitivity of the implementation selection | `benchmarking/e2e/navi/run_pi_sensitivity.sh` (SARAD and N-BEATS sweeps, profile stability), then `benchmarking/e2e/sensitivity/run_pi_sensitivity_knee.sh`; profile stability on the server: `benchmarking/e2e/sensitivity/run_profile_stability.sh`. The table's ranges: `benchmarking/e2e/sensitivity/replay_selection.py` and `replay_knee.py`, over the processed results | Pi, Server; replay anywhere | Pi ~9 h, Server ~1.5 h, replay seconds |
| Table: memory of replicated models | `benchmarking/e2e/navi/scripts/run_model_memory.py` (3 repetitions), with the optimizer's assessment re-measured by `benchmarking/e2e/navi/run_pi_memory_assess_rerun.sh`                                                                                                                                                                                                      | Pi | ~2 h |
| Inference-configuration ablation, time series and audio (`e2e-ts.pdf`, `e2e-audio.pdf`) | `benchmarking/e2e/navi/run_pi_ablation_rerun.sh`, with the UDF baselines from `benchmarking/e2e/navi/run_pi_ablation_udf_rerun.sh` (3 repetitions each)                                                                                                                                                                                                                        | Pi | ~2 h |
| Throughput vs. offered load (`systems-rate-sweep-throughput.pdf`) | `benchmarking/e2e/navi/scripts/run_systems_rate_sweep.sh` (7 rates, 3 repetitions; run by `benchmarking/e2e/navi/run_pi_systems_rerun.sh`), with the Flink and TorchServe arms at their tuned settings rerun by `benchmarking/e2e/navi/run_pi_flink_sweep_lanes1.sh` and `run_pi_ts_sweep_workers3.sh`                                                                         | Pi | ~2 h |

In total, the experiments take ~67 h of machine time (Pi ~30 h, server ~36 h, laptop ~2 h), or ~1.5 days when the three machines run in parallel.

The baselines' code is in `benchmarking/e2e/baselines/` (Flink + OpenVINO job and its JNI bridge, TorchServe handlers), and
the NebulaStream queries of the Pi experiments in `benchmarking/e2e/navi/queries/`. The queries of the threading
experiment are system tests in `nes-systests/inference/`.
